# MineSweeper

A Kotlin Android starter app. The first screen is immersive fullscreen with a top-right overflow menu. The center area is a placeholder for the screen design.

## Project

- Package: com.nsdey.minesweeper
- Minimum Android version: API 23
- Compile and target API: 37
- Android Gradle Plugin: 9.5.0
- Kotlin: enabled through Android Gradle Plugin built-in Kotlin support
